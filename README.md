# Калькулятор стоимости каркасного дома

Локальное приложение для строительной компании: считает стоимость каркасного дома
по прайсу, показывает цену за м² и собирает смету по разделам.

Работает офлайн на компьютере пользователя, запускается двойным кликом
и **не требует интернета** (кроме режима обновления цен из онлайн-таблицы).
Установка не нужна — приложение открывается в браузере как локальная страница.

## Возможности

- загрузка прайса из `.xlsx` — 145 позиций, 16 разделов;
- параметры объекта ползунками: площадь дома, периметр стен, площадь фасада
  и кровли, остекление, число свай, терраса/навес;
- позиции сметы с галочками и автоматическим количеством;
  количество можно поправить вручную;
- уровень цен: минимальная → базовая → максимальная, плюс процент резерва
  и коэффициенты (накладные, технадзор);
- итоговая стоимость объекта, цена за м², разбивка по разделам с диаграммой;
- экспорт сметы в файл;
- кнопка **«Обновить данные»** — подтягивает актуальные цены
  из онлайн-таблицы по ссылке.

## Запуск

Нужен установленный Python 3.10+.

```
project\запуск.bat
```

Приложение откроется по адресу `http://127.0.0.1:8791`.
Порт можно изменить переменной окружения `KALK_PORT`.

## Как пользоваться

1. **«Загрузить данные»** — выбрать файл `.xlsx` из папки `project\Данные`.
2. Задать параметры дома ползунками.
3. Отметить нужные позиции сметы галочками.
4. **«Показать итог»** — стоимость дома и цена за м².
5. **«Экспорт»** — выгрузить смету. **«Новый расчёт»** — сбросить параметры.

## Формат файла прайса

Первый лист — `Справочник затрат`, первая строка — заголовки:

| ID | Раздел | Подраздел | Наименование позиции | Тип позиции | Единица измерения | Минимальная цена, ₽ | Базовая цена, ₽ | Максимальная цена, ₽ | Статус | Основание цены | Комментарий |

В репозитории лежит `project/Данные/Прайс_каркасный_дом_2026_ОБЕЗЛИЧЕННЫЙ.xlsx` —
пример структуры, в нём цены скрыты. Чтобы калькулятор считал по вашему прайсу,
положите свой файл с такими же колонками в папку `project/Данные`.

## Технологии

- Python — **только стандартная библиотека** (`http.server`, `zipfile`,
  `xml.etree`): чтение `.xlsx` без сторонних зависимостей;
- HTML/CSS/JavaScript без фреймворков.

(см. `.gitignore`).
